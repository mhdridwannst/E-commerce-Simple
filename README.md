# WANNN STORE

Simple e-commerce website built with Next.js for UKM Software Development PENS.

## About

WANNN STORE is a minimal online store that displays products across several categories (Men's Clothing, Women's Clothing, Jewelry, Electronics). Users can browse products and add them to the cart.

This project was created as part of the Software Development assignment at UKM Software Development PENS.

## Features

- Product listing with category labels
- Product cards with image, name, price, and Add to Cart button
- Simple cart counter in the header
- Search bar (UI)
- Responsive grid layout
- Clean, minimal design

## Tech Stack

- **Framework**: Next.js
- **Styling**: CSS / Tailwind (sesuaikan dengan yang kamu pakai)
- **Language**: JavaScript / TypeScript (sesuaikan)

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/username/wannn-store.git

# Go into the project directory
cd wannn-store

# Install dependencies
npm install

# Run the development server
npm run dev
